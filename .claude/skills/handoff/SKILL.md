# handoff — 세션 인계

다음 세션이 이 파일 하나만 읽고 바로 이어서 작업하도록 상태를 기록합니다. 추측이나 희망 사항이 아니라 **검증된 사실과 실패한 시도**를 적습니다.

## 대상 파일

- 인자로 경로를 받으면 그 파일에 씁니다. 없으면 프로젝트 루트의 `.handoff.md`에 씁니다. 사용자가 `STATE`라고 하면 루트의 `STATE`에 씁니다.
- 파일이 이미 있으면 **먼저 읽습니다.**
  - 이번 세션에 끝낸 ⏳ 항목은 ✅로 옮깁니다.
  - 아직 유효한 ⏳·❌ 항목은 그대로 남깁니다.
  - 해결된 ❌ 항목은 지웁니다.
  - 파일 전체를 새로 쓰지 말고 현재 상태 기준으로 갱신합니다.

## 작성 절차

1. **근거 수집**: 아래 명령을 실제로 실행하고 출력을 근거로 씁니다.
   - `date '+%Y-%m-%d %H:%M'`
   - `git branch --show-current`
   - `git status --short -uall` (`-uall`이 없으면 새 폴더 안의 파일이 `?? .claude/`처럼 폴더 하나로 묶여 보입니다)
   - `git diff --stat`
   - `git log --oneline -5`
   - 이번 세션에서 실행한 빌드·테스트·실행 명령의 실제 출력
2. **분류**: 아래 체크리스트를 통과시킵니다.
3. **파일 쓰기**: 출력 템플릿대로 갱신하고, 사용자에게 파일 경로와 세 구획의 항목 수를 알립니다.

## 분류 체크리스트

### ✅ 완료
- [ ] 항목마다 증거가 같은 줄에 있는가 (`명령 → 출력`, `파일:줄`, 커밋 해시, 테스트 통과 수)
- [ ] 증거는 이번 세션이나 방금 실행한 명령에서 나왔는가 (기억·추정이면 ⏳로 내림)
- [ ] 코드만 쓰고 실행·확인하지 않은 것을 ✅로 올리지 않았는가 → "작성함, 미검증"으로 적어 ⏳에 둠
- [ ] 테스트 실패·스킵이 있으면 그 사실을 숨기지 않고 적었는가

### ❌ 시도 → 실패
- [ ] 시도한 접근, 실패 원인, 다음 대안이 모두 적혀 있는가
- [ ] 원인은 오류 메시지·출력 원문 기준인가 ("안 됨"만 쓰지 않음)
- [ ] 다음 세션이 같은 접근을 다시 시도하지 않도록 구체적인가 (명령·옵션·파일명 포함)

### ⏳ 다음 할 일 / 미착수
- [ ] 맨 위 항목이 바로 시작할 다음 단계이고, 시작점(`파일` 또는 `명령`)이 붙어 있는가
- [ ] 아직 손대지 않은 요구 사항이 빠짐없이 있는가 (CLAUDE.md의 목표와 대조)
- [ ] 사용자가 결정해야 해서 멈춘 항목은 "결정 필요:"로 시작하는가

### 공통
- [ ] 항목은 한 줄씩이고 단락이 없는가
- [ ] 세 구획 헤더가 모두 있는가 (비었으면 `- 없음`)
- [ ] 비밀값(토큰, 키, 개인 경로의 자격 증명)이 들어가지 않았는가

## 출력 템플릿

```markdown
# Handoff — <현재 상태 한 줄>

> 갱신: <YYYY-MM-DD HH:MM> · 브랜치: `<branch>` · 변경: <git status --short 요약, untracked 포함>

## ✅ 완료 (검증된 것만)
- [x] <한 일> — 증거: `<명령 → 출력 / 파일:줄 / 커밋 / 테스트 결과>`

## ❌ 시도 → 실패 (반복 금지)
- [ ] <시도한 접근> — 원인: <오류·출력 근거> → 대안: <있으면>

## ⏳ 다음 할 일 / 미착수
- [ ] <바로 이어갈 다음 단계> — 시작점: `<파일 / 명령>`
- [ ] <아직 손대지 않은 것>
- [ ] 결정 필요: <사용자가 정해야 하는 것>

## 컨텍스트 메모
- <모르면 다음 세션이 같은 오류를 낼 결정·제약·환경 설정>
```

## 원칙

- 다음 세션 관점에서 씁니다. "내가 한 일" 목록이 아니라 "이어받는 사람이 알아야 할 것"입니다.
- 각 항목은 한 줄로 씁니다. 명사형 종결("통과함", "없음")을 허용합니다.
- CLAUDE.md나 git log에 이미 있는 내용은 반복하지 않고 위치만 가리킵니다.
- ✅❌⏳ 외의 이모지와 장식은 넣지 않습니다([anti-ai-slop](../../rules/anti-ai-slop.md)).
